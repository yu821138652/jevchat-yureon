# 离线校准工具

本目录保存模型判断层的离线校准脚本和测试样例，服务于 `jevchat（Yureon）` 的个人开发。

- `questions.py`：判断问题和排序问题定义。
- `jev_client.py`：兼容接口的请求封装。
- `calibrate.py`：使用环境变量中的接口密钥运行校准。
- `fixtures/`：脱敏测试样例。

运行前请自行配置 `OPENROUTER_API_KEY`。脚本不会把密钥写入文件；运行报告和缓存目录不应提交到 Git。判断模型的问题指令保留英文，是因为当前模型接口对英文指令的效果更稳定，聊天内容仍保留中文原文。

这些脚本不是 Android App 的运行必需组件，也不代表上游项目的发布工具。
