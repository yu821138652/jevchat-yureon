# jevchat (Yureon)

This is a personal Android fork of Jev Chat Assistant.

Current focus:

- WeChat and Xiaohongshu testing on Honor Magic devices.
- Contact selection and per-contact local conversation history.
- Manual history preloading and automatic incremental updates.
- Sequence-based filtering to avoid recording the same visible history page repeatedly.

The project is maintained for personal use. It does not automatically send messages. API keys and conversation history remain outside the repository in the app's private storage.
